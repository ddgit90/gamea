# ABYSS DIVER ―迷宮都市の日々―

現代の街にある巨大な迷宮に潜る「ハクスラ × ローグライク × 生活シム」のブラウザゲームです。
HTML・CSS・JavaScriptだけで動くので、インストールもビルドも要りません。

## 遊び方

### パソコンで遊ぶ
`index.html` をダブルクリックしてブラウザで開くだけで遊べます。

### GitHub Pages で公開して遊ぶ（スマホからも遊べる）
1. GitHubで新しいリポジトリを作る（例：`abyss-diver`）
2. 「Add file → Upload files」で **index.html を1つアップロード**するだけ（CSSもJavaScriptも全部この中に入っている）
3. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、Branch を `main`・`/ (root)` にして Save
4. 1〜2分待つと `https://（ユーザー名）.github.io/abyss-diver/` で遊べる（反映状況は「Actions」タブで確認できる）

セーブデータはブラウザ内に保存されます。別の端末へ移したいときは、メニュー（Esc / ≡）の「セーブデータを書き出す」で作ったファイルを、移した先の端末で読み込んでください。
